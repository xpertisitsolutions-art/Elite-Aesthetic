ELITE AESTHETICS CEBU — PRODUCTION IMAGE SET V2

Purpose
This package contains the higher-resolution original JPG assets collected for the Elite Aesthetics Cebu website build. It is intended to replace the smaller/blurrier image assets currently being used in Google AI Studio.

IMPORTANT
- Upload this ZIP to the Elite Aesthetics Google AI Studio project before the next image-integration prompt.
- Do not use screenshots of the current website as production assets.
- Do not upscale low-resolution assets.
- The source JPGs in this package are copied without additional JPEG re-encoding.
- The 206x206 social/profile thumbnails were intentionally excluded because they are not suitable for large website placements.
- Existing generated/QA screenshots were intentionally excluded.

Folders
01_Brand — Elite Aesthetics logos
02_Clinic_Interior — clinic/reception/treatment-room/interior photography
03_Treatment_Clinical — CO2 laser and Hydrafacial imagery
04_Treatment_Promotional — treatment/service promotional graphics
05_Team_Doctors — team and doctor/staff photographs
06_Promotions_Campaigns — campaign/cover-style promotional assets
07_Reference_Not_For_Production — reserved for assets requiring additional review

Production rule
Use real supplied Elite Aesthetics imagery only. Do not fabricate doctors, patients, clinic rooms, results, certifications, awards, or testimonials. If an asset contains promotional text or a price, treat it as a promotional graphic rather than as a permanent factual price source.

Image quality
The package includes assets up to approximately 2048px on the long side. Wide hero placements should preferentially use the supplied landscape Hero Image assets rather than cropping a portrait asset into a wide banner.

Next step
After uploading this ZIP, do not run a new redesign prompt. First perform the controlled V2 asset replacement/integration pass, then visually inspect the homepage again.
